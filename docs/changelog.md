# Literature Feed: changelog

## 0.0.1 (not released)
- Zotero sync: the command **Sync ticked papers** and the status block's **Sync** button send every ticked paper to your Zotero library: a new item (journal article, preprint or thesis) in the feed's collection and project collection with the tag `feed/<name>`, or, when the DOI is already there, the collections and tag added to the existing item. The note line gets an "in Zotero" link. Missing collections are created after you confirm. Not seen against a real library yet.
- Reading inbox: the command **Scan now** searches OpenAlex for every switched-on feed and writes or extends this week's note (`<year>-W<week> Reading inbox.md`): a status block with **Scan now** and a disabled **Sync**, one collapsible callout per feed, one checkbox line per paper, a separate list for papers with no abstract. Ticks survive a rescan; papers already listed are not listed again. A `show: home` block gives a small card for another note (flat inside a callout such as a Home column, in Lab Kit's card colours when that theme is on); a paper found by two feeds counts once in the "waiting" figures; buttons are outlined pills like Lab Kit's; a line says what the latest scan found, including how many papers the feed rules dropped; with more than one feed switched on, a row per feed shows the same. Not seen in Obsidian yet.
- API keys are kept in Obsidian's secret storage, not in the vault; the settings file holds only the secret's name. Keys saved as plain text by an earlier build are moved on first load.
- Settings tab: OpenAlex and Zotero keys, Zotero user ID, inbox and archive folders, scan day; a feed list (switch on or off, edit, duplicate, delete, export and import as `.json`); a feed editor (topics, concept groups with roles, drop and lower terms, years from, Zotero collection, project) with warnings and a **Test** button that runs a real OpenAlex search and shows how the papers would score. Settings are read tolerantly and reload when `data.json` changes outside Obsidian. Not seen in Obsidian yet.
- First feed as an importable file: `docs/feeds/lipoic-acid-copolymers.json`.
- Matching: a paper with no abstract whose title does not show the required terms is "Unchecked" (to be listed apart in the inbox), not Dropped.
- Matching: a paper with no abstract is scored on its title alone and ranks at most Possible. In the inbox note such a paper carries "title only".
- Repo scaffold: a plugin that loads and unloads, build, test and lint set up, CI workflows. No feature yet.
