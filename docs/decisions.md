- 2026-10-13 — A paper can be dismissed at any stage (also after it was sent to Zotero or read), for one of two reasons: **not relevant** (a firm no in the search statistics, overriding an earlier tick, send or read: the judgement after reading is the better signal) or **no access** (counted as wanted, with its own report column, because the search found a paper the user wanted). It is stored in the note line as checkbox `[-]` plus a hidden marker `%%dx:n%%` or `%%dx:a%%`; the Zotero and Read links stay and the plugin never changes Zotero on a dismissal. Dismissed beats every other status, counts as done for the archive at once, is never sent. A sent paper's tick box is locked; the data still treats an unticked line in the In Zotero list as a resend request, reached by a **Send again** link — (user, chat 2026-10-13; plan-mode approval)
